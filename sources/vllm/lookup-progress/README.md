# LMCache缓存结果推进修复

本目录保存基于固定LMCache 0.5.6的本地差异，不声称是官方已合并提交。原文件与修改后文件、差异文件的完整SHA256见`manifest.json`，派生第三方代码继续遵循Apache-2.0。

结果推进复用原适配器状态机，并从每轮连接器元数据回调调用；不再要求当前轮次还有计算token预算。它不修改请求准入、GPU块分配、PD传输、MTP或正常读锁释放时机，不增加后台线程。

完整构建顺序、CPU核验、分段阈值和只准备下次启动的边界见[专项说明](../../../docs/09-缓存结果推进与分段.md)。原版本升级后必须重新确认元数据回调仍在预算为零时执行，不能仅放宽散列继续套用补丁。
